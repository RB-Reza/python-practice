# Guessing Game

This is my third Python project. It is a fun interactive game where the computer tries to guess the user's number.

## About this project
The program generates a random number between 1 and 99. The user thinks of a number and gives hints (H for Higher, L for Lower, C for Correct) to help the computer guess it correctly. It also narrows down the range after each guess.

## How to run
To play the game, run this command in your terminal:
`bash
python guessing_game.py
